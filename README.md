A full-stack messaging application built around real-time communication, authentication, and a responsive user experience.

- ⚡ **Real-time communication:** Socket.IO client-server integration.

- 🗄️ **Backend:** Node.js, Express, MongoDB, and Mongoose.

### 📚 Book-Stash — AI-Powered Book Management

A full-stack book management application combining a modern interface, structured data management, cloud-based book cover storage, and AI-powered summaries and note translation.

- 📖 **Frontend:** React 18 and TypeScript with Mantine UI, shadcn/ui, and Tailwind CSS.
- ⚡ **Server state:** TanStack React Query v5 for data fetching, caching, and synchronization.
- 🧠 **AI integration:** OpenAI SDK with GPT-4o for summaries and note translation.
- 🗄️ **Backend:** Node.js, Express, TypeScript, Drizzle ORM, and PostgreSQL.
- 🛡️ **Validation:** Zod and drizzle-zod for runtime request validation.
- ☁️ **Cloud storage:** Google Cloud Storage through Replit Object Storage for book cover images.
- 📤 **File uploads:** Uppy for file-upload interfaces and progress tracking.

**Tech Stack:** React 18 · TypeScript · TanStack Query · Mantine · Tailwind CSS · Node.js · Express · Drizzle ORM · PostgreSQL · OpenAI SDK · Google Cloud Storage
